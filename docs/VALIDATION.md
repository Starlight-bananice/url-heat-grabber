# v0.6.0 验证

验证日期：2026-09-05。macOS arm64 与 Windows x64 正式安装包统一发布于 v0.6.0；应用显示版本为 0.6.0，内部构建号为 4。

## macOS 已完成

- **39 项功能测试通过**：覆盖原有平台解析、分享文案提取、重复链接处理、Excel/CSV 导入、零与空值、状态说明、文件保存失败、任务进度，以及贴吧四项指标和旧进度兼容。
- **5 项桌面流程测试通过**：使用真实 Tk 事件循环和受控页面 worker，覆盖完成、结果筛选、历史载入、续跑、停止、保存失败、无效目录和最小窗口布局。每个场景独立启动一个应用进程。
- **贴吧解析验证**：此前单条真实贴吧实测获取了转发、评论、点赞、收藏，导出后重新读取 Excel 核对。正式版沿用该解析器，重新运行打包应用的 Chrome、本地页面解析和 Excel 导出自检；未进行验证码识别或互动操作。
- **Mac 构建验证通过**：Python 编译、PyInstaller 构建、arm64 架构、应用签名完整性与 ZIP 完整性检查。使用 macOS 原生归档保留应用结构，实际解压核对中文应用名和签名。
- **图标验证通过**：外部透明圆角、内部完整不透明，检查 32 px 与 128 px 外观；包含 macOS ICNS、Windows ICO 和侧栏 PNG。

## Windows 已完成

- **39 项功能测试、5 项桌面流程测试通过**：在 GitHub Windows 云端环境运行，覆盖导入、状态解析、任务记录、续跑、停止保存、导出失败和小窗口布局。Mac 专用解析测试明确标注其平台；贴吧入口和进度兼容覆盖 Windows、Mac 两种分支。
- **修复 Windows 小窗口布局**：使用 Microsoft YaHei UI，1080 × 760 窗口中结果表高度为 113 px；检查开始、打开 Excel、结果表及状态栏均处于窗口内。
- **打包程序抓取与导出通过**：EXE 使用内置 Python、Tk、Selenium Manager 启动本机 Chrome 并导出 Excel；从子进程环境移除外部 Python 配置和已知 ChromeDriver 路径，使用独立目录重新准备驱动。
- **四项数据核对通过**：只将导航目标替换为本地 HTML 样本，其余使用真实抓取流程。Excel 样本重复链接被合并，贴吧样本读到分享 7、评论 42、点赞 108、收藏 6，不支持网址明确标注。导出的 XLSX 重新读取核对。样本数值不代表线上帖子数据。
- **应用资源与窗口截图已检查**：版本为 `0.6.0`，应用名称为“链接热度抓取”，包含新版 Windows ICO 和侧栏图标；正常启动与最小窗口均保存截图。
- **正常退出与包完整性通过**：通过 Windows 标题栏关闭事件退出，主事件循环结束，进程返回 0；下载 ZIP 后检查 CRC、SHA256 与 EXE 的 x64 架构。

Windows 安装包来自 [GitHub Actions 构建 33925998841](https://github.com/Starlight-bananice/url-heat-grabber/actions/runs/33925998841)，构建提交为 `b996af135d84fdd0799e234472803dee2ca11e43`。Mac 应用使用相同源码在本机构建；之后仅调整 Mac 归档方式和验证文档。构建保留 `windows-validation` 测试报告和截图，样本均为合成数据。


## 验证边界

受控测试不代表平台实时可用率。尚未完成全平台大批次回归、另一台干净 Mac 的首次组件准备，以及普通用户 Windows 电脑上的首次启动和真实平台批量验收。Windows 云端测试使用已安装的 Chrome，不代表无浏览器电脑的首次 Chrome 下载验收。

Mac 应用使用 ad-hoc 签名，未完成 Apple Developer ID 公证。首次准备浏览器组件需要联网，平台验证、登录与访问限制仍可能影响结果。

本地抓取记录、诊断页面、真实输入链接和结果文件均不包含在源码发布中。
