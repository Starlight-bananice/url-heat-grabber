# macOS 0.6.0 预览构建 3 验证

验证日期：2026-09-05。此版本为 Apple Silicon Mac 预览版本。

## 已完成

- **38 项功能测试通过**：覆盖原有平台解析、分享文案提取、重复链接处理、Excel/CSV 导入、零与空值、状态说明、文件保存失败、任务进度，以及贴吧四项指标和旧进度兼容。
- **5 项桌面流程测试通过**：使用真实 Tk 事件循环和受控页面 worker，覆盖完成、结果筛选、历史载入、续跑、停止、保存失败、无效目录和最小窗口布局。每个场景独立启动一个应用进程。
- **单条贴吧实测通过**：完整浏览器抓取流程实际获取转发、评论、点赞、收藏，导出后重新读取 Excel 核对。正常页面和真实验证页分别保留其状态；未进行验证码识别或互动操作。
- **Mac 构建验证通过**：Python 编译、PyInstaller 构建、arm64 架构、应用签名完整性与 ZIP 完整性检查。
- **图标验证通过**：外部透明圆角、内部完整不透明，检查 32 px 与 128 px 外观；包含 macOS ICNS、Windows ICO 和侧栏 PNG。

## 复现测试

```bash
python -m unittest discover -s tests -v
# 需要可用桌面窗口服务；不会访问目标网站
python tests/desktop_integration.py
```

## 验证边界

受控测试不代表平台实时可用率。尚未完成全平台大批次回归、另一台干净 Mac 的首次组件准备，以及 Windows 实机测试或预览安装包构建。

Mac 应用使用 ad-hoc 签名，未完成 Apple Developer ID 公证。首次准备浏览器组件需要联网，平台验证、登录与访问限制仍可能影响结果。

本地抓取记录、诊断页面、真实输入链接和结果文件均不包含在源码发布中。
